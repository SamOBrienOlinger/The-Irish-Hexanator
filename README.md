# The Irish Hexanator

A collaborative frontend project that creates playful, fictional Irish hexes from randomly selected phrase parts.

**HTML · CSS · JavaScript**

[Visit the website](https://samobrienolinger.github.io/The-Irish-Hexanator/) · [Getting started](#getting-started) · [Repository guide](#repository-guide) · [Checks](#checks-and-review) · [Credits](#credits-and-reuse)

## What you can explore

- A name-driven, three-part generator.
- An About page introducing the project team.
- Themed artwork and a custom 404 page.

## Getting started

Requires a browser and a local HTTP server. Python 3 provides one without installing application packages.

```bash
git clone https://github.com/SamOBrienOlinger/The-Irish-Hexanator.git
cd The-Irish-Hexanator
python3 -m http.server 8000 --bind 127.0.0.1
```

Open [localhost:8000](http://localhost:8000). Serve the repository over HTTP so module imports, relative assets and page links resolve correctly.
