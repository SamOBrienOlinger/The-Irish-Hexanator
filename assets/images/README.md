# Completion artwork

`hex-reveal-frame.webp` is an optimised static copy of the first, text-free frame of the emerald reveal animation generated in this project conversation. It is used only by the Step 4 completion card and its PNG export. The original source was supplied as `emerald_hexanator_curse_reveal.png` (an animated GIF despite that filename).

The concept GIFs contain a fixed example name and curse, so those text-bearing frames are deliberately not played. Live HTML and canvas text use the visitor's actual name and chosen phrases. The existing original leprechaun is composited separately and remains unchanged on the homepage. Short CSS animations recreate the mist, mascot entrance, staggered lines and sparks after a successful Step 4 action; reduced motion shows a static card. No generated image substitutes for a working HTML control.
